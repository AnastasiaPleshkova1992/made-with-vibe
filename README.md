# VibeCraft Hero

Создай Hero-секцию для лендинга-портфолио специалиста по вайбкодингу.

Используй стиль, цветовую палитру и расположение элементов из загруженного референса.

Сделай светлый тёплый фон, тёмно-серый текст и мягкие сливовые и нежно-розовые акценты. Для заголовка используй крупный элегантный шрифт, для остального текста — простой и хорошо читаемый. Сохрани много свободного пространства, как в референсе.

Над заголовком размести небольшую подпись:

VIBE CODING × WEB DESIGN × AI

Основной заголовок:

Превращаю идеи в красивые веб-продукты

Слово «красивые» выдели сливовым цветом и курсивом.

Подзаголовок:

Создаю лендинги и простые веб-продукты, сочетая AI-инструменты, продуманную структуру и современный дизайн.

Добавь две кнопки:

«Смотреть проекты» и «Обсудить идею».

Справа размести визуальный элемент в стиле референса — фрагмент современного веб-интерфейса. Не используй фотографию человека.

Адаптируй секцию под мобильные устройства. На смартфоне сначала должен идти текст и кнопки, затем визуальный элемент. Текст должен хорошо читаться, а кнопками должно быть удобно пользоваться.
